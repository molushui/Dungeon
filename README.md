# 7 Days Dungeon

> 这是我为了入门游戏开发而完成的一个简单demo，也是我的第一个游戏开发项目，所以这只是一个开发难度不高的小游戏demo。
> 这也是我「7 天独立游戏开发挑战」的产物：用 7 天时间，用Godot从零做出第一款能从头打到通关的 2D 地牢射击游戏demo。


俯视角、鼠标瞄准、一层层往上打，第 5 层对上 BOSS——系统不多，但从移动、射击、血量、升级到结算，每一环都是自己一行行码出来的。

---

## 玩法

- **俯视角射击**：WASD 走位，鼠标决定枪口方向，左键开火。
- **一层一层往上打**：清光当前层的敌人自动进入下一层，第 5 层是 BOSS 房。
- **升级成长**：击杀敌人获得经验，升级后攻击力 +1、最大生命 +1 并回满血，升级所需经验逐级翻倍。
- **受伤与无敌帧**：初始 3 点生命，挨打后有 0.5 秒无敌时间，不会瞬间被围死。
- **结算**：打过 BOSS 会统计通关用时、杀敌数和最终等级；倒下了按 R 重开。

## 操作

| 操作 | 按键 |
| :--- | :--- |
| 移动 | `W` `A` `S` `D`（方向键同样可用） |
| 射击 | 鼠标左键，朝准星方向发射 |
| 暂停 / 继续 | `空格` |
| 重新开始 | `R` |

## 数值一览

| 项目 | 规则 |
| :--- | :--- |
| 玩家移速 | 300 像素/秒（8 方向，已做归一化，斜向不会更快） |
| 玩家生命 | 初始 3 点，升级时 +1 并回满 |
| 升级所需经验 | 8 → 16 → 32 → …（每级翻倍），升级时攻击力 +1 |
| 每层敌人数 | `2 + 层数 × 3`，上限 15 |
| 敌人血量 | `1 + (层数 - 1)`，上限 5 |
| 敌人移速 | `100 + 层数 × 20`，上限 350 |
| 击杀经验 | 当前层数（打 BOSS 额外给 `50 + 层数 × 10`） |
| BOSS 属性 | 20 血、冲刺 400 像素/秒、撞击 2 点伤害、弹幕 1 点伤害 |

## 技术实现

### 房间与难度推进

`room_manager.gd` 是整个流程的中枢：它维护当前层数、存活敌人数和杀敌统计，负责清场（上一层的敌人和残留子弹用 `queue_free()` 回收，中间隔一帧再操作，避免在信号回调里直接删节点）、按层数计算刷怪数量与属性，并在第 5 层切换到 BOSS 流程。敌人死光后延迟 1 秒进入下一层，给玩家一点喘息。

### BOSS 状态机

`boss.gd` 用枚举状态机组织行为：

```
IDLE（后摇） ──0.8s──▶ CHASE（追击）
   ▲                        │ 每 2~4 秒随机
   │                        ├──▶ DASH（朝玩家高速冲刺，撞到就结算伤害）
   └────────────────────────┴──▶ AOE （以自身为中心射出 8 方向弹幕）
```

血条是跟着 BOSS 走的 `ColorRect`，按 `hp / max_hp` 直接改宽度。

### 子弹的两套逻辑

- **玩家子弹**（`bullet.gd`，`Area2D`）：命中 `enemies` 组的节点就扣血，撞墙销毁，2 秒后自动回收防止泄漏。
- **BOSS 子弹**（`bossbullet.gd`，`CharacterBody2D`）：用 `move_and_collide()` 拿碰撞法线做 `direction.bounce(normal)` 反弹，最多弹 3 次，3 秒后回收——所以 BOSS 房的弹幕会在地形间来回弹，走位压力明显更大。

### 一些踩过的坑

开发过程中顺手记的 bug 笔记：

- **暂停后收不到输入**：`get_tree().paused = true` 之后，节点默认 `process_mode = inherit`，输入会跟着一起冻住。解决办法是把必须一直在线的部分（UI 的 `CanvasLayer`）设成 `always`；但反过来也踩了坑——一开始让玩家节点继续响应输入，结果 GAME OVER 界面上角色还能跑，最后又把它改回来。
- **只有第一只敌人能被打死**：Godot 实例化重名节点时会自动改名成 `@CharacterBody2D@2` 这种，按节点名字判断的击杀逻辑就失效了；改成统一加入 `enemies` 组，用 group 判定。
- **实例化节点报错**：场景还没完全初始化就 `add_child` 会崩，`RoomManager` 里用 `await get_tree().process_frame` 和 `call_deferred` 把这层时序捋平。

### 工程组织

- 玩家 / 敌人 / BOSS / 子弹各自「场景 + 脚本」成对存在，全部平铺在项目根目录，不追求目录层级，7 天内看得过来最重要。
- UI 全部集中在 `main.tscn` 的 `CanvasLayer` 下，由 `ui.gd` 统一更新，玩家脚本只负责把数据推过去。
- `sound_manager.gd` 用字典预加载音频，对外只暴露 `play(name)`，后面加音效不用改调用方。
- `menu.gd` 里用了一个 `static var skip_menu`，让「按 R 重开」能跳过菜单直接进游戏。

## 目录结构

```text
7d-ayproject/
├── project.godot                  # 项目配置：输入映射、Jolt 物理、D3D12 渲染
├── main.tscn                      # 主场景：玩家、四面墙、UI、房间管理器
├── menu.tscn / menu.gd            # 主菜单（开始 / 退出）
│
├── player.gd                      # 玩家：移动、射击、生命、经验升级
├── enemy.tscn / enemy.gd          # 普通敌人：追踪玩家、近身造成伤害
├── boss.tscn / boss.gd            # BOSS：状态机、冲刺、弹幕、头顶血条
├── bullet.tscn / bullet.gd        # 玩家子弹
├── bossbullet.tscn / bossbullet.gd # BOSS 子弹（撞墙反弹）
├── room_manager.gd                # 层数推进、刷怪、通关统计
├── ui.gd                          # HUD、暂停、胜利、GAME OVER
├── sound_manager.gd               # 音效管理
│
├── sound/victory.mp3              # 通关音效
└── *.png                          # 角色与敌人贴图（占位素材）
```

## 快速开始（暂时没有导出为exe）

1. 安装 [Godot 4.7](https://godotengine.org/download)（Standard 版即可，无需 .NET）。
2. 克隆仓库后，用 Godot 的「导入」选中 `project.godot`。
3. 按 `F5` 运行。仓库里没有提交 `.godot/` 缓存目录，首次打开会自动重新导入资源，稍等几秒即可。
4. 想打包给别人玩：`项目 → 导出`，添加 Windows Desktop 预设。

## 已知问题

- **敌人撞到玩家后会自杀式消失**：这是为了绕过「偶发卡关」加的临时方案，副作用是杀敌数和经验的增长不正常，难度曲线也偏软。
- **金币和存档没有做**：企划书里列了金币，当前版本只实现了经验与等级。
